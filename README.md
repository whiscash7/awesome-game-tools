# awesome-game-tools



Hello! I will be covering game tools that than are good for game developers to use. These tools are not exclusive to game programmers, but mostly can be used by all game developers.



The tools I will be covering are

* Obsidian
* Visual Studio
* Blender
* Unity
* Godot
* Itch.io
* Krita
* Asset Forge
* Autodesk Maya
* Reaper



### Obsidian

Obsidian is a note taking app. While not exclusively for game developers, it is quite popular among them. It can be used to plan projects, write game design documents, and map out concepts or mechanics and such. What makes Obsidian special is how all of its files are stored locally on your computer, so you actually own your own notes. Additionally, Obsidian has the ability to link files together to connect ideas and keep your work organized. It is heavily recommended as one of the best note taking tools around.

[https://obsidian.md/](https://obsidian.md/)



### Visual Studio

Visual studio is an IDE, which is an Integrated Development Environment. It is used frequently for writing code. It is very useful to connect code with other programs, like unity. It can also be used on its own to make games completely from scratch as well. It is free to use and available to download on Windows. 



I recommend this one (Visual Studio Community), because it does not require a license and can be downloaded off of the internet

[https://visualstudio.microsoft.com/vs/community/](https://visualstudio.microsoft.com/vs/community/)



### Blender

Blender is a tool for 3D modeling and for game developers to make 3D models for their games. It is free and able to be downloaded off of the internet. The models created can be exported from blender and imported into game making software. Additionally, you can make animations for models in blender, as well as add textures through the tool itself.

[https://www.blender.org/](https://www.blender.org/)

### Unity

Unity is a game engine. Code for Unity is in C#. It is very commonly used for making games, but not used for higher end projects by big corporations, or games with intense graphics. It supports both 2D and 3D games.

[https://unity.com/](https://unity.com/)

### Godot

Godot is a game engine that supports both 2D and 3D games. Godot allows the use of its own language, GDScript, or the use of C# or C++, or any other language, using an extention. Godot games can be released on all platforms and has a wide variety of tools for game developers to use.

[https://godotengine.org/](https://godotengine.org/)

### Itch.io

Itch.io is a tool that is used by many game developers. For the most part, it is used as a store, however, on the game development side, it is used as a place to publish games for free. Itch.io also hosts game jams where you have a certain amount of time to make a video game and upload it. It is a great space for all kinds of game developers to share their work and find people from the game industry.

[https://itch.io/](https://itch.io/)

### Krita

Krita is a free software that is able to be downloaded off of the internet. It can be used for drawing to make sprites and textures. It is completely free and open source and has a wide variety of art tools that are able to be used. It is commonly used by Game Developers because of its free cost and versatility. 

[https://krita.org/en/](https://krita.org/en/)

### Asset Forge

For game developers, it is a space for them to find art assets that they need for their games. Asset Forge has a wide variety of assets for both 2D and 3D games that are completely free to use after the one time purchase.

[https://kenney.nl/tools/asset-forge](https://kenney.nl/tools/asset-forge)

### Autodesk Maya

Autodesk Maya is a tool for 3D modeling. It is an industry standard for large studios. It is an alternative to Blender and provides the same tools as Blender. Like blender, the models created can be imported into a game making software. Additionally, you can make animations for models in Maya, as well as add textures through the tool itself.

[http://autodesk.com/products/maya/overview](http://autodesk.com/products/maya/overview)

### Reaper

Reaper is a tool that can be used by game developers to mix music or sound effects for their games. It costs $60 dollars, but offers a 60 day free trial, and is heavily recommended as a good DAW (Digital Audio Workstation). It is recommended despite its cost because instead of it being a subscription, it is a one time purchase, and the tools it provides is often said to be worth the cost. 

[https://www.reaper.fm/](https://www.reaper.fm/)
